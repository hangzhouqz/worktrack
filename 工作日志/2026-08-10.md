## 根因分析（改前代码）

- 日历格子点击直接调用 `openLogSheet(ds)` → 永远打开**空白新增表单**；`#deleteLog` 按钮只在传入 `logId` 时显示。
- 结果：某天已有多条记录时，界面上**看不到已有记录**，也无法选中某一条去改/删，备注更无入口。这正是指令 1、3 的根因。
- 统计页原本是两个独立 `.card`，用户要求重构成单 section 两大块（指令 2）。

## 本次改动（已完成，语法校验通过）

### 一、新增「日期详情抽屉」（解决指令 1 + 3）
- `index.html` 新增 `<div class="sheet" id="daySheet">`：顶部显示 `日期 + 周几 + 当日合计`，中部 `#dayLogList` 列表，底部「+ 新增工时」。
- `app.js` 新增：
  - `openDaySheet(date)` / `closeDaySheet()`：打开/关闭详情
  - `renderDayLogs(date)`：列出当日**全部**记录（项目 · 工种 / 起止·时长 / 备注），每条带「编辑」「删除」；备注用 `textContent` 渲染（防 XSS）
  - `closeLogForm()`：关闭录入表单时若来自详情（`returnToDay` 为真），刷新列表并**回到详情**
- 日历格子点击由 `openLogSheet(ds)` 改为 `openDaySheet(ds)`。
- 录入表单（`#logForm`）的取消/背景关闭（`#logCancel`/`#logBackdrop`）改为调 `closeLogForm`，保存/删除成功后也走 `closeLogForm` → 自动回到当日详情。
- 删除记录前 `confirm` 二次确认。

### 二、统计界面重写（解决指令 2）
- `index.html` 统计视图改为：一个 `<section class="stats-section">` 内含两大块 `.card.stats-block`——「按项目」「按工种」，各自带数量提示 `#projCount`/`#wtCount`。
- `app.js` `renderStats()` 在渲染后写入类目数量（`${Object.keys(...).length} 个`）。
- 数据逻辑天然独立：项目按名字聚合、工种按名字聚合，多项目共用同一工种时工种合计自动汇总，互不混淆（原代码已正确，本次固化呈现）。

### 三、配套
- `sw.js` 缓存版本 `wt-v2` → `wt-v3`（强制已安装用户拉取新代码）。
- `styles.css` 新增 `.stats-section` / `.stats-block__hint` / `.day-head` / `.day-list` / `.day-item` 等样式，沿用既有 CSS 变量与主题。
