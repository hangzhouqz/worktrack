# 工时统计系统 · 方案设计

> 创建时间：2026-08-02
> 目标平台：小米手机（MIUI / HyperOS · Android）
> 状态：方案待确认，未开始编码

---

## 一、需求

1. 可安装在小米手机上，**不能出现兼容性冲突**
2. 界面足够简洁
3. 按日期填写工时
4. 改动记录与命令留档在 `工作日志/`，防止上下文过长导致任务逻辑冲突

---

## 二、技术方案选型

三种可选安装路径对比：

| 方案 | 安装方式 | 兼容性风险 | 开发难度 | 离线 | 是否需签名/匹配架构 |
|------|---------|-----------|---------|------|------------------|
| **A · PWA** | 浏览器"添加到主屏幕" | **极低** | 低 | 支持 | 否 |
| B · 原生 APK | 安装 APK | 中 | 高 | 支持 | 是（minSdk / arm64-v8a / 签名） |
| C · Capacitor 混合 | 安装 APK | 中 | 中 | 支持 | 是（仍需 Android SDK） |

### 决策：采用方案 A（PWA）

理由：
- 小米自带浏览器（基于 Chromium）、Chrome、Edge 均**原生支持 PWA 安装**
- 完全不碰 CPU 架构、`minSdkVersion`、APK 签名等任何会触发兼容性冲突的环节
- Service Worker 实现离线缓存，IndexedDB 本地存储，断网也能填工时
- 数据只在手机本地，不上云、不联网，隐私可控
- 后续若你坚持要真正的 `.apk` 文件，可用 **PWABuilder** 把这套 PWA 一键打包成签名 APK，仍然零原生编译冲突

## 三、运行架构

```
小米手机 (Android)
  └─ Chrome / 自带浏览器
       └─ 工时统计 PWA（安装后桌面图标，全屏运行）
            ├─ 界面层：日历视图 + 工时表单 + 统计
            ├─ Service Worker：离线缓存
            └─ IndexedDB：本地工时数据存储
                 └─ 仅本机，可导出 CSV 备份
```

安装流程：打开网址 → 浏览器菜单"添加到主屏幕" → 桌面生成图标 → 点开即用全屏。**全程无需开启"未知来源"，无需 APK 签名。**

## 四、功能清单（首版）

| 模块 | 功能 |
|------|------|
| 日历主页 | 月视图，每天显示当日工时数与加班标记 |
| 填写工时 | 选择日期 → 开始/结束时间 → 自动算时长 → 备注 → 加班标记 |
| 编辑/删除 | 点某天即可改或删当天记录 |
| 统计 | 按周 / 月汇总总工时、加班工时、出勤天数 |
| 设置 | 浅色/深色/跟随系统主题切换、CSV 导出、数据清空 |

字段精简，只保留：日期、开始时间、结束时间、时长（自动）、备注、是否加班。

---

## 五、技术栈

- HTML5 + CSS3 + Vanilla JS（不引重框架，保证轻量与零依赖冲突）
- IndexedDB（数据）+ Service Worker（离线）
- `manifest.json`（PWA 安装配置，含图标、名称、主题色）
- 主题色：可后续按你的偏好设定，默认浅色 + 深色双主题

---

## 六、交付与部署

1. 编码完成后，本地起一个静态服务（如 `python -m http.server` 或 Node 静态服务）
2. 手机与电脑**同一局域网**，手机浏览器访问电脑 IP 即可使用并"添加到主屏幕"
3. 如需公网访问，可选 CloudStudio 部署（静态站点托管）
4. 如需 `.apk`，再用 PWABuilder 打包
